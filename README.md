INSTRUCTIONS TO ACCESS THE WEB APPLICATION

1) Download the 'ZOR app final' zip folder 
2) Once downloaded, click on the file to open it 
3) Click on 'ZOR app' file in the folder
4) Double click on Index.html to launch the live server to the web application*
5) Enjoy your experience with ZOR!


*The website server may fail to launch at times due to some backend issues from the host. If clicking on the html file does not launch the application, please try using another device to launch the server.

*if the issue still persists, open using another browser (e.g. Microsoft Edge) or make sure the website is accessed from the ZIP File.

Note: Make sure you have a zip extractor on your computer!
